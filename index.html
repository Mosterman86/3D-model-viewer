About this project
This gallery is an early proof of concept for presenting three-dimensional digitized objects from the Wolfsonian collection in a browser-based interactive environment. The models here represent an iterative, experimental approach: formats, workflows, and presentation methods will continue to evolve as the project develops.
How it works
The viewer is built on Three.js, a JavaScript library that uses WebGL to render 3D graphics directly in the browser — no plugins or downloads required. Models are loaded as OBJ files, a widely supported, geometry-focused format commonly produced by photogrammetry and structured-light scanning workflows. The OBJLoader parses mesh geometry at runtime, and an OrbitControls interface handles user interaction — allowing objects to be rotated, panned, and zoomed via mouse, trackpad, or touch. Lighting is simulated using a combination of ambient and directional lights to approximate real-world surface conditions. Annotations are positioned as interactive overlay markers tied to the canvas, linking areas of the object to contextual information about its history and significance.
